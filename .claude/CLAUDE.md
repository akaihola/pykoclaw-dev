## Practices

- Always write useful insights, practices and rules applicable to all pykoclaw
  repos/components/plugins immediately into `./.claude/CLAUDE.md` (this file).
  Details specific to a single repo can go to that repo's `./*/.claude/CLAUDE.md`.

## Project structure

- Each `./pykoclaw*/` directory is a separate Git repository clone
- `./pykoclaw/` — Pykoclaw core package
- Sibling directories next to `./pykoclaw/` are separate Pykoclaw plugins
